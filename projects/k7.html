K7 Autonomous Security Robot

An outdoor four-wheeled autonomous patrol platform built for military bases, airports, and critical infrastructure. Alpha Prototype Gate approved; contributing to a U.S. Air Force SBIR contract.

What I built

I architected the end-to-end autonomy stack on top of ROS 2 Humble and Autoware Universe, and led a cross-functional team of more than twelve engineers from concept through alpha prototype. The vehicle operates at low-speed-vehicle regime in pedestrian-dense and mixed-traffic outdoor environments, so the design favors deterministic safety, layered fail-safes, and an orchestration model that can switch behaviors in real time.

Architecture highlights

  • Localization: NDT scan matching against a pre-built point-cloud map plus an Extended Kalman Filter fusing GNSS, IMU, wheel odometry, and visual odometry. Sub-10 cm accuracy at alpha.
  • Mapping: Lanelet2 vector maps with per-site projector origin; offline PCD maps from a LIO-SAM fork; multi-floor support.
  • Perception: Multi-modal pipeline — LiDAR + radar + thermal + RGB + IMU + GPS — with CenterPoint 3D detection on TensorRT, multi-object Kalman tracker (CV/CTRV/bicycle models), map-based prediction, and a probabilistic occupancy grid. 360° obstacle detection at 20 Hz.
  • Planning: Three-layer Autoware planner — behavior path planner, behavior velocity planner, motion velocity planner — tuned for patrol-zone turnarounds, pedestrian-heavy environments, and dock approach via hybrid A*.
  • Control: MPC lateral controller (kinematic bicycle, OSQP solver, 50 ms loop) + PID longitudinal controller with slope compensation, behind a vehicle command gate validated by six independent safety checks.
  • Orchestration: BehaviorTree.CPP v4 sits above the Autoware stack as the orchestration substrate — modular subtrees switch between manual, service, user, and autonomous modes, dock entry / exit, and patrol routes. Reactive sequences enable real-time mode switching without explicit state-transition tables.
  • Real-time systems: PREEMPT_RT Linux kernel; hardware-heartbeat safety watchdog; CAN-bus vehicle interface with fail-safe stop behavior on any chassis fault or e-stop.
  • Edge AI: RealSense D456 stereo + NVIDIA Jetson Orin for media-stack inference; TensorRT-optimized models for object detection, multi-object tracking, and acoustic classification with under 100 ms inference latency.
