FedRAMP Authorization Program

Led the security architecture and authorization program that produced the first autonomous security robot to achieve FedRAMP Authority to Operate on U.S. federal networks — opening the federal and DoD market.

What I built

FedRAMP authorization is a multi-year program that converts a commercial product into one a federal agency can legally deploy. I led the architecture work that closed the gap between commercial autonomy and FedRAMP-aligned cryptography, identity, audit, and continuous monitoring — coordinating with security engineering, infrastructure, and compliance to land each control on time.

Architecture highlights

  • End-to-end encryption: TLS 1.3 mutual authentication for every channel between the robot, the cloud control plane, and operator workstations. No clear-text transport anywhere on the wire.
  • Data at rest: AES-256 encryption for all stored telemetry and media.
  • Secure boot: Architected a TPM 2.0 hardware root-of-trust boot chain so any tampering at the firmware layer becomes detectable.
  • Cloud infrastructure: Led the migration to FedRAMP-authorized AWS GovCloud. VPC isolation, IAM least-privilege policies, CloudTrail audit logging, GuardDuty threat detection.
  • Continuous ATO: Set up continuous monitoring of authorization-relevant signals so the ATO doesn't go stale between annual reviews.
