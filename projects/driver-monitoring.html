Driver Monitoring System

A camera-based drowsiness detection pipeline that combines facial-landmark geometry with a temporal LSTM — 96% accuracy at detecting sustained eye closure across drivers, lighting, and head poses.

What I built

Drowsiness is a temporal signal, not a single-frame one. I built a pipeline that detects 68 facial landmarks every frame, computes the Eye Aspect Ratio over a sliding window, and feeds the EAR sequence into a small LSTM that classifies "alert" vs "drowsy" with 96% accuracy.

Architecture highlights

  • Facial landmark localization: dlib 68-point model running per-frame.
  • Eye Aspect Ratio: Geometric blink-detection signal derived from the landmark coordinates around each eye.
  • Temporal classifier: LSTM network trained on EAR sequences; learns the pattern of sustained closure that distinguishes a blink from microsleep.
  • Real-time inference: Pipeline kept latency low enough to run on automotive-grade compute alongside the AEB stack.

Tech stack

  • dlib
  • OpenCV
  • Eye Aspect Ratio
  • LSTM
  • PyTorch
  • Python

Outcome

  • 96% drowsiness classification accuracy across drivers and lighting.
  • Deployed alongside the AEB stack in the Columbus AI test vehicles.
