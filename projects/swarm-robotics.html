Swarm Robotics Simulation

A PyBullet swarm simulator running Reynolds flocking, potential-field navigation, and consensus-based formation control across ten differential-drive robots with stable collision avoidance.

What I built

Built a multi-robot simulation environment that lets formation-control algorithms be developed and tuned before hitting hardware. Each robot runs local rules — alignment, cohesion, separation, plus a potential-field obstacle response — and the swarm converges to a desired formation without any central coordinator.

Architecture highlights

  • Flocking: Reynolds' alignment / cohesion / separation rules implemented per-robot.
  • Navigation: Potential-field method for obstacle avoidance, layered with the flocking forces.
  • Formation control: Consensus-based formation control for differential-drive kinematics.
  • Physics: PyBullet for collision-resolved simulation of all ten robots.

Tech stack

  • PyBullet
  • Reynolds flocking
  • Potential field
  • Consensus control
  • Python
  • NumPy

Outcome

  • Stable 10-robot formations with no collisions in obstacle-rich scenes.
  • Reusable simulation environment for downstream multi-robot algorithm work.
