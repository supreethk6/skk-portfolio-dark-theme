ICM & ACM Modular IoT Platforms

A modular edge-compute platform that powers on-device AI threat detection across the robot fleet — built so a single hardware family supports plug-and-play sensors and OTA-deployable workloads.

What I built

I architected the compute and communication layer that sits between the robot's sensors and the cloud. The goal: keep latency-critical inference on-device, keep the network resilient across intermittent connectivity, and let the platform team ship new models without re-flashing hardware in the field.

Architecture highlights

  • Compute: NVIDIA Jetson Orin as the edge inference substrate. Containerized microservices with Docker, orchestrated by Kubernetes for OTA updates and graceful rollouts.
  • Hardware abstraction: A clean HAL boundary that allows new sensor classes to be wired in without touching higher-level perception code.
  • Communication: Multi-protocol stack with a store-and-forward queue for intermittent connectivity. 99.9% message delivery measured across the deployed fleet.
  • Edge AI: Quantized TensorFlow Lite models for on-device inference. INT8 quantization cut model size 4× while maintaining 95%+ accuracy, enabling real-time threat detection without a cloud round-trip.

Outcome

  • 4× smaller models with 95%+ retained accuracy.
  • 99.9% message delivery across intermittent networks.
  • Single hardware family supporting multiple robot platforms.
