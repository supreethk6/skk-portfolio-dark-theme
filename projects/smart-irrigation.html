IoT Startup Project

Smart Irrigation System

A wireless sensor mesh covering soil moisture, water level, and weather, paired with a mobile app for remote valve control — an IoT stack that lets a single farmer manage a long-range farm from their phone.

What I built

Designed the full system — from the embedded sensor nodes scattered across the field, through the mesh network that gets their readings home, to the mobile app a farmer actually uses. The goal was long-range coverage with minimal cellular dependency, so the network had to relay through other nodes.

Architecture highlights

  • Sensor network: Distributed nodes measuring soil moisture, tank water level, and local weather.
  • Mesh networking: Nodes relay through each other for long-range farm coverage without per-node cellular cost.
  • Mobile app: React Native client with a Firebase backend for real-time monitoring and remote valve control.

Tech stack

  • Embedded C
  • Mesh networking
  • React Native
  • Firebase
  • Soil-moisture sensors
  • Weather sensors

Outcome

  • Long-range farm coverage via mesh networking, no per-node cellular subscription required.
  • Remote valve control from a phone, anywhere with mobile data.
